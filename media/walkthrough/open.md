# The course map

Click the **MEAN Stack Basics** icon in the Activity Bar. You will see nine tracks, from HTML to a final project:

1. HTML
2. CSS
3. JavaScript
4. Node.js
5. Express
6. MongoDB
7. Angular
8. AngularJS (legacy)
9. Capstone project

Open any lesson, or press **Continue Learning** to jump to the next one you have not finished.

Tip: press `Ctrl+Alt+M` (`Cmd+Alt+M` on Mac) to search lessons by topic, or type `ms` in the Command Palette to see every command.
