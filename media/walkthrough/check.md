# Check your code

1. In a lesson, press **Open exercise file**. The file is created in a folder called `MEAN Stack Basics` in your home folder. You can change the folder in settings.
2. Edit the file and save it.
3. Press **Check my code**. Each check shows **Passed** or **Needs work** with a short reason.

Stuck? Show a hint. There are three, and each one helps a little more. After three failed checks, or after all three hints, you can compare your file with the reference solution.

Checks run on your computer. Your code is never sent anywhere.
