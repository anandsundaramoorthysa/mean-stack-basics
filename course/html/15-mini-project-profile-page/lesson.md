Time to put it all together. You will build a one-page profile that uses most of the ideas from this track. There is no new syntax here, so use the earlier lessons and the MDN reference when you are stuck.

## Plan before you type

A good page starts as an outline:

```text
header   -> your name (h1) and a nav with links to sections
main
  section "About"   -> a paragraph, a photo with alt text
  section "Skills"  -> a list
  section "Projects"-> a table with caption and header cells
  section "Contact" -> a small form with labels
footer   -> copyright line
```

## Build it in layers

1. Write the skeleton: doctype, `html lang`, head with `title`, body.
2. Add the landmarks (`header`, `main`, `footer`) with empty sections.
3. Fill each section one at a time, saving and checking as you go.
4. Connect the nav links to the section ids.

Use the checklist as you work. Each item matches something you practised earlier. When all pass, open the page and press Tab through it to make sure it makes sense without a mouse.
